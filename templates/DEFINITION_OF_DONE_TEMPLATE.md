# Plantilla: Definition of Done (DoD)

Para que una tarea se considere **COMPLETADA**, debe cumplir los siguientes puntos:

## Desarrollo
- [ ] El código compila sin errores.
- [ ] Se han seguido los estándares de codificación.
- [ ] No hay código comentado o "TODOs" pendientes.
- [ ] La lógica de negocio está aislada en el dominio.

## Testing
- [ ] Tests unitarios pasan exitosamente.
- [ ] Tests de integración (si aplica) pasan exitosamente.
- [ ] Cobertura mínima alcanzada en las partes críticas.

## Documentación
- [ ] Javadoc/TSDoc completado.
- [ ] OpenAPI/AsyncAPI actualizado.
- [ ] README del módulo actualizado si es necesario.

## Calidad & Seguridad
- [ ] Revisión de código realizada y aprobada.
- [ ] Escaneo de vulnerabilidades básico realizado.
- [ ] Validación de aislamiento de Tenant verificada.

## Despliegue
- [ ] Verificado en el entorno de Docker Compose local.
