# EC-017 — Order Management

Parte 1 define el dominio de órdenes comerciales y prepara la implementación de la Parte 2.

Order consume los contratos de Commerce y conserva un snapshot comercial inmutable. No duplica pricing, carrito, productos vendibles, pagos, inventario ni logística.
