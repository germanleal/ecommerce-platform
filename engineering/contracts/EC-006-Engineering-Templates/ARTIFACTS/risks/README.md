# Template Risks

## Riesgos mínimos documentados

### Riesgos Técnicos
- Plantillas desactualizadas.
- Versiones incompatibles.
- Duplicación.
- Divergencia entre proyectos.

### Riesgos Organizacionales
- Equipos utilizando templates antiguos.
- Baja adopción.
- Falta de mantenimiento.

### Riesgos IA
- Generación usando plantillas incorrectas.
- Creación de estructuras nuevas.
- Eliminación accidental de archivos estándar.

## Formato de riesgo

- ID
- Descripción
- Impacto
- Probabilidad
- Severidad
- Mitigación
- Responsable
