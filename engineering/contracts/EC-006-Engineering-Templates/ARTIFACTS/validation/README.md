# Template Validation

## Validaciones automáticas

### Templates
- [ ] Todas las plantillas existen.
- [ ] Todas poseen identificador.
- [ ] Todas poseen versión.
- [ ] Todas poseen estado.
- [ ] Todas poseen historial.

### Backend
- [ ] Todos los servicios fueron creados usando el template oficial.
- [ ] Arquitectura Hexagonal respetada.
- [ ] Documentación mínima presente.

### Frontend
- [ ] Todos los proyectos utilizan el template oficial.
- [ ] Organización por Features.
- [ ] Design System separado.

### Ingeniería
- [ ] Todos los Engineering Contracts poseen:
  - AI_CONTEXT
  - REVIEW
  - CHECKLIST
  - QUALITY
  - VALIDATIONS

### Documentación
- [ ] Todos los README siguen el estándar.
- [ ] Todos los CHANGELOG siguen el estándar.
- [ ] Todas las ADR utilizan el mismo formato.
