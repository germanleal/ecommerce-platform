# EC-006 Engineering Templates Artifacts

Este directorio contiene el catálogo oficial de plantillas definidas en EC-006 Parte 1.

## Objetivos

- Catalogar las plantillas oficiales del proyecto.
- Establecer la clasificación de templates por tipo.
- Definir las reglas generales de construcción de plantillas.
- Documentar la organización física de las plantillas.
- Registrar las reglas de versionamiento.
- Enumerar las restricciones que deberán respetar todos los Engineering Contracts posteriores.
- Documentar la gobernanza, el ciclo de vida, las validaciones y la auditoría de plantillas.
