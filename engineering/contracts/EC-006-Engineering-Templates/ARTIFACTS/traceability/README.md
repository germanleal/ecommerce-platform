# Template Traceability

## Matriz de trazabilidad

La trazabilidad debe permitir recorrer:

```
Engineering Contract
↓
Template
↓
Proyecto
↓
Microservicio
↓
Archivo
↓
Responsabilidad
↓
Bounded Context
↓
Capability
↓
Objetivo del Negocio
```

## Reglas

- Todas las plantillas deben poder rastrearse hasta el contrato origen.
- No debe existir plantilla sin trazabilidad.
- La matriz debe mantenerse actualizada con cada cambio.
