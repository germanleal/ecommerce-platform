# Template Audit

## Objetivo

Definir el proceso de auditoría para plantillas oficiales.

## Propósito

Verificar:
- cumplimiento del estándar;
- uso correcto de templates;
- ausencia de modificaciones no autorizadas;
- consistencia documental.

## Resultado

La auditoría debe generar un informe con:
- hallazgos;
- no conformidades;
- recomendaciones;
- acciones correctivas.

## Proceso

1. Revisión de estructuras de plantillas.
2. Verificación de versionamiento.
3. Evaluación del uso en proyectos.
4. Confirmación de estado `Approved`.
5. Generación de informe de auditoría.
