# Marketplace Glossary

| Term | Definition |
|---|---|
| Tenant | Organización propietaria de datos y tiendas. |
| Store | Canal comercial perteneciente a un Tenant. |
| Catalog | Organización de categorías y productos de una Store. |
| Product | Oferta comercial identificable de una Store. |
| Category | Clasificación de productos. |
| Variant | Configuración vendible de un Product. |
| SKU | Identificador único de una Variant dentro del alcance definido. |
| Price | Valor monetario de una oferta. |
| Inventory | Disponibilidad operativa de una oferta. |
