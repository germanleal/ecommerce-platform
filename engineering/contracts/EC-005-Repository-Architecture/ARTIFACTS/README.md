# EC-005 Repository Architecture Artifacts

Este directorio contiene la documentación resultante de EC-005 Parte 2: estructura interna de backend, frontend, shared, infraestructura y engineering.

## Contenido

- `backend/`: estructura de microservicios y convenciones de proyectos Java.
- `frontend/`: organización de apps React y design system.
- `shared/`: librerías compartidas y contratos neutrales.
- `infrastructure/`: componentes de infraestructura.
- `engineering/`: documentación de ingeniería y gobernanza.

## Objetivo

- Establecer la estructura oficial del repositorio según EC-005.
- Definir la organización interna de cada proyecto.
- Asegurar consistencia y escalabilidad para nuevos servicios y equipos.
