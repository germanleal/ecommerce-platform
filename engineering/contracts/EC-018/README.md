# EC-018 — Payments & Billing

Este directorio contiene el Engineering Contract EC-018: análisis y diseño del dominio de pagos y facturación.

## Objetivo

Definir formalmente el dominio Payment y el dominio Billing para que la Parte 2 pueda implementar:

- Payment Aggregate
- PaymentAttempt
- Payment Method
- Persistencia PostgreSQL
- Flyway
- APIs REST
- Kafka
- Gateway Abstraction
- Idempotency
