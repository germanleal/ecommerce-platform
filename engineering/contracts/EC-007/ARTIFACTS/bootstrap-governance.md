# Bootstrap Governance

## Versionamiento

El Bootstrap se versiona como producto independiente mediante Semantic Versioning. La versión publicada es `v1.0.0`.

## Flujo de cambio

Solicitud → análisis arquitectónico → evaluación de impacto → actualización de EC-007 → Architecture Review → aprobación → actualización del Bootstrap → versionamiento → publicación.

## Reglas

- Los desarrolladores utilizan únicamente proyectos existentes.
- No se renombra, mueve ni elimina la estructura base.
- Los frameworks y tecnologías deben estar aprobados por los contratos vigentes.
- Cada cambio actualiza README, CHANGELOG y documentación relacionada.
- Las inconsistencias se reportan; no se resuelven improvisando arquitectura.
