# Commerce Security Model

Permisos iniciales:

- `COMMERCE_CONFIGURE`.
- `PRICE_CREATE`.
- `PRICE_UPDATE`.
- `PRODUCT_ENABLE_SELLING`.
- `PRODUCT_DISABLE_SELLING`.

La autorización combina identidad EC-010A, Tenant Context EC-010B, rol, permiso y recurso comercial. Nunca se crean usuarios ni autenticación propia.
