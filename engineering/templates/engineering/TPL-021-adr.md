## Objetivo
Definir la plantilla oficial para Architecture Decision Records.

## Alcance
- Estructura obligatoria de ADR.
- Reglas de contenido.
- Formato uniforme.

## Estructura requerida
```
ID

Título

Estado

Fecha

Contexto

Problema

Alternativas

Decisión

Consecuencias

Riesgos

Referencias

Engineering Contracts relacionados

Cambios futuros
```

## Reglas clave
- Cada ADR debe ser específica y clara.
- No mezclar múltiples decisiones en un solo ADR.
- Mantener referencias a contratos relevantes.
