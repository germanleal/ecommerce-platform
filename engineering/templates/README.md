# Engineering Templates

Este directorio contiene las plantillas oficiales reutilizables del proyecto.

## Estructura

- `backend/`: templates para microservicios y librerías Java.
- `frontend/`: templates para aplicaciones React y librerías TypeScript.
- `shared/`: templates para contratos, librerías compartidas y clientes.
- `infrastructure/`: templates para configuración de infraestructura.
- `documentation/`: templates para documentos estándar.
- `engineering/`: templates para ADR, contratos, reviews, métricas y validaciones.
