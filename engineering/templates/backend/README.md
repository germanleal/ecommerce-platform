# Backend Templates

Este directorio contiene plantillas oficiales para proyectos backend.

## Plantillas definidas

- `TPL-001-springboot-service.md`
- `TPL-002-java-library.md`
- `TPL-003-config-server.md`
- `TPL-004-api-gateway.md`
- `TPL-005-service-discovery.md`

## Propósito

Proveer plantillas estructurales para microservicios Java Spring Boot y componentes de plataforma.

## Uso

Estas plantillas deben utilizarse como base para crear nuevos servicios backend en `backend/`.
