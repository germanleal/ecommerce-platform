# Frontend Templates

Este directorio contiene plantillas oficiales para proyectos frontend.

## Plantillas definidas

- `TPL-006-react-marketplace.md`
- `TPL-007-react-backoffice.md`
- `TPL-008-react-tenant-admin.md`

Proveer plantillas para aplicaciones React y para el design system reutilizable.

## Uso

Estas plantillas deben utilizarse como base para crear nuevas aplicaciones y librerías frontend en `frontend/`.
