# Shared Templates

Este directorio contiene plantillas oficiales para librerías y contratos compartidos.

## Plantillas definidas

- `TPL-011-java-library.md`
- `TPL-012-typescript-library.md`
- `TPL-013-shared-contracts.md`
- `TPL-014-shared-clients.md`

## Propósito

Proveer plantillas para recursos reutilizables que no contienen lógica de dominio específica.

## Uso

Estas plantillas deben utilizarse como base para crear nuevos módulos compartidos en `shared/`.
