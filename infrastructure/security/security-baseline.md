# Security Baseline

- No secretos en código, repositorio, imágenes o logs.
- Dependencias e imágenes con versiones explícitas.
- Validación de entradas y errores sin detalles internos.
- Autenticación y autorización obligatorias para APIs protegidas.
- Redes aisladas y mínimo de puertos expuestos.
- Vulnerabilidades `CRITICAL` bloquean el quality gate.
