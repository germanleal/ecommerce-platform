# 20. Estándares de Codificación

## Java (Backend)
- Seguir las Google Java Style Guide.
- Uso de `final` para variables locales y parámetros cuando sea posible.
- Evitar el uso de `null`, preferir `Optional`.
- Stream API para manipulación de colecciones.
- Excepciones personalizadas por dominio.

## TypeScript/React (Frontend)
- Uso de Functional Components y Hooks.
- Tipado exhaustivo de Props y States.
- Preferir interfaces sobre tipos para objetos de datos.
- Estructura de archivos: un componente por archivo.
- Uso de Early Returns para mejorar la legibilidad.

## General
- Comentarios solo donde el código no sea auto-explicativo.
- Mantener los métodos y funciones cortos y con una única responsabilidad.
- Eliminar código muerto y comentarios obsoletos.
