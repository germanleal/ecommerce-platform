# 13. Estrategia Open Source First

## Filosofía
Priorizamos el uso de software libre y de código abierto para evitar el vendor lock-in y fomentar la transparencia y la comunidad.

## Criterios de Selección
1. **Licencia**: Preferencia por MIT, Apache 2.0 o BSD.
2. **Comunidad**: Actividad constante, documentación robusta y adopción enterprise.
3. **Estándares**: Cumplimiento de estándares abiertos (OIDC, SQL, OpenAPI).

## Stack Seleccionado
- **Java/Spring Boot**: Ecosistema maduro y abierto.
- **PostgreSQL**: La base de datos relacional open source más avanzada.
- **Kafka**: Estándar de facto para mensajería distribuida.
- **Keycloak**: Líder en gestión de identidades open source.
- **React/Radix/Tailwind**: Ecosistema frontend líder y abierto.

## Contribución
Fomentamos la contribución a los proyectos open source que utilizamos cuando detectamos mejoras o errores.
