# 16. Guías de Documentación

## Documentación de Código
- Código auto-documentado mediante nombres claros.
- Javadoc para APIs públicas y lógica compleja.
- TSDoc para componentes y hooks de React.

## Documentación de API
- Generación automática de especificaciones OpenAPI (Swagger).
- Documentación de contratos de eventos (AsyncAPI) para Kafka.

## Documentación Arquitectónica
- Uso de ADRs (Architecture Decision Records) para registrar decisiones importantes.
- Diagramas C4 para visualizar la arquitectura en diferentes niveles.

## Engineering Handbook
- Este manual es la "Fuente de Verdad" para todo el equipo de ingeniería. Debe mantenerse actualizado.
