# 24. Glosario de Términos

- **Tenant**: Empresa u organización cliente de la plataforma.
- **Multi-Tenancy**: Arquitectura que permite a una sola instancia de software servir a múltiples clientes.
- **Bounded Context**: Límite explícito dentro del cual vive un modelo de dominio.
- **Arquitectura Hexagonal**: Estilo arquitectónico que aísla la lógica de negocio de los detalles técnicos.
- **Evento de Dominio**: Algo que sucedió en el dominio y que es relevante para otras partes del sistema.
- **Keycloak**: Sistema de gestión de identidad y acceso open source.
- **Radix UI**: Librería de componentes primitivos sin estilo para construir sistemas de diseño accesibles.
- **AI Ready**: Estado de un sistema preparado para integrar capacidades de inteligencia artificial de forma nativa.
