# 03. Alcance (Scope)

## En Alcance (In Scope)
- Plataforma SaaS Multi-Tenant.
- Gestión de Organizaciones, Tiendas, Catálogos y Pedidos.
- Autenticación centralizada con Keycloak.
- Arquitectura de Microservicios basada en Eventos.
- Frontend React moderno con Radix UI.
- Infraestructura containerizada (Docker).

## Fuera de Alcance (Out of Scope) - Fase Inicial
- Implementación real de modelos de IA (Solo preparación).
- Apps móviles nativas (Solo Web Responsive).
- Integración con ERPs externos de terceros.
- Soporte para múltiples idiomas (Inicialmente Español).
